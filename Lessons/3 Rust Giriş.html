Giriş

Yazılım Nedir?

Yazılım, bir bilgisayara yapıcağı işleri özel bir dil ile anlatılan yazılara ve komutlara yazılım denir.

Donanım Nedir?

Donanım, bir bilgisayar içerisindeki görebildiğim ve dokunabildiğimiz tüm nesnelerdir.
Yazılım dillerinin hepsi bir donanım üzerinde çalışır. Yani burada bir ilişki vardır. Eğer yazılım var olmasaydı donanımlar işlevsiz devre kartlarına, donanım var olmasaydı ise yazılım var olmazdı.

Low-Level ve High-Level

Low-Level, bir yazılım dilinin insan diline uzak, High-Level ise insan diline yakınlığını belirten bir belirteçtir.
Low-Level diller, donanıma en yakın ve insan diline en uzak dillerdir. Genellikle sürücü yazılımı ve işletim sistemi kodlarken Low-Level dillere ihtiyaç duyarız. Örnek olarak ise C, C++, Assembly ve Rust dilleri örnek verilebilir. Bu dökümantasyonda içini dışını öğreneciğimiz C++ dili ise Low-Level yani donanıma yakın diller arasındadır.
High-Level diller, donanıma uzak ve insan diline en yakın dillerdir. Genellikle basit uygulamalar,giriş seviye algoritmaları ve GUI gibi yerlerde kullanılır. Örnek olarak ise Python, Java, C# ve Ruby dilleri örnek verilebilir.

Yazılım Dilleri

Yazılım dilleri, bilgisayarlara özel olarak üretilmiş ve komut vermek amacıyla yazılan bir dildir. Yazılım genel olarak donanıma elektrik sinyalleri aracığıyla ne yapması gerektiğini anlatan komut dizisidir. Dünya üzerinde sekiz binden fazla yazılım dili olasada hepsinin temelde yaptığı işlem donanımla fiziksel işlemler gerçekleştirmektir. Bazı farklar hariç hangi yazılım dilini yazdığımız fark etmez. Mantık aynı fakat sözdizimi yani Syntax farklıdır.

Rust Nedir?

Rust, düşük seviyeli bir programala dilidir.

Kısa Tarihçesi

2006 yılında Mozilla çalışanı olan Graydon Hoare, söylenenlere göre apartmanındaki asansörün bozulmasıyla aklına gelen bir fikir ile projeye başlamıştır. O zaman bir çok yerleşik sistemlerde kullanılan olan dil C veya C++ idi. Yazılmasından kaynaklı C ve C++ dillerinde bellekler bazen düzgün kullanılamaz ve program çöker. Böyle bir durumda asansöründe başına gelen buydu ki Graydon Hoare'ın aklına bir fikir geldi. "Eğer bellek yönetimini dil kendisi yaparsa, çökmeler yaşanmaz." Fikri bu idi. Fakat bu durum çöp toplayıcısı yani Garbage Collector gerektiriyordu. Düşük seviyeli bir programlama dilinde de Garbage Collector olması, ciddi sıkıntılar doğurabilirdi. Bu sebeble Garbage Collector'sız fakat bellek yönetimini dilin kendisinin yaptığı bir proje için kolları sıvadı. 2000 yılına kadar da Mozilla vakfı dışına çıkmamıştır. Ardından 2009 yılının sonlarına doğru Mozilla vakfı projeyle ilginmeye başladığı zamanki sıralarda bir çok mühendis Rust için dili geliştirmeye başlamışlardı. İlk kararlı sürüm 2012 yılında duyruldu. Pek çok yazılımcı Rust'ı çok sevdi. Öyleki 2016 yılındandır beri en çok sevilen yazılım dili olarak seçilmiştir.

C ve C++ Dillerindeki Farkları

Rust her ne kadar düşük seviyeli bir programlama dili olsada, müdillerinden yani C ve C++'dan farklılıkları vardır. Aşağıdaki tabloda verilmiştir.
Konu C ve C++ Rust
Bellek Güvenliği Bellek güvenliği programcının elindedir. Bellek güvenliği Ownership(Sahiplenme) denilen bir sistem ile Rust programlama dilinde yapar. Garbage Collector'dan çok farklıdır.
Paket Desteği Merkezi bir paket/kütüphane sistemi yoktur. Paket/Kütüphane gibi ihtiyaçlar için Cargo uygulaması ile sağlanır.
OOP(Obje Yönelimli Programlama) Desteği C yoktur. Fakat C++'da desteği fazladır. Rust'da bellek güvenliği açısından OOP desteklenmez.
Çapraz Platformluk C ve C++ programlama dillerinde sınırlıdır. Çoğunlukla çapraz platformlu kodlar yazılabilir.

Rust Kurulum

Şimdi Rust'u kurabiliriz...

Kurulum

İlk olarak Rust'ın resmi sitesine gidelim. İşletim sistemizin uygun olan ".exe" dosyasını tıklayarak indirelim. İndikten sonra çalıştıralım.
Enter tuşuna basıp kurulumu başlatalım. Ardından bir komut satırı açıp "rustc" yazalım. Eğer uzun bir çıktı alıyorsak, kurulmuş demektir.
Bu işlemleri Windows işletim sistemi içindi. Şimdi Linux için kurulum yapalım.
Tek yapmamız gereken bir Shell açıp curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh yazıp Enter'a basalım. Çıkan seçim ekranında da yine Enter tuşuna basarak kurulumu gerçekleştirelim.

IDE Seçimi

Ben gelişme ortamı olarak Visual Studio Code'u kullanıcağım. Ancak siz istediğiniz geliştirme ortamını kullanabilirsiniz.
Visual Studio Code kullananlar, uygun eklentimizi kuralım.
Artık Rust programlama dilinde uygulamalar geliştirebiliriz.

İlk Proje

İlk projemizi oluşturmak için bir klasör oluşturalım ve şu komutu girelim;
cargo new ilkProjemiz
Ardından oluşan klasörde Visual Studio Code ile açalım. Artık ilk projemiz oluşmuş oldu...

İlk Program

VS Code ile açtığımız klasörde şu komutuda çalıştıralım;
cargo run
Kodun çıktısında "Hello, world!" görebilirsiniz. Tebrikler, ilk programınızı derleyip çalıştırdınız!
Şimdi kodları inceleyelim.
// <- Bu işaretler yorum satırı anlamına gelir. Yorum satırı ise uygulamanın görmediği kısımlardır. İlerki sayfalarda daha detaylı işlenicektir

fn main() // Programın başı. Tüm programlar bu kısımdan başlarlar 
{ // Kod bloğun başlangıcı
    println!("Hello, world!"); // println! komutu, bizlere konsola bazı ifadeler yazdırmamızı sağlayan bir araçtır
} // Kod bloğunun sonu

Şimdi ise o tırnaklar içerisine "Rust programlama dilini öğreniyurum" yazmanızı istiyorum. Ardından cargo run komutu ile çıktıyı gözlemlemenizi istiyorum.

Derlenme Süreci

Derlenme; bir programala dilinin, başka dile çevrilmesi sonucu ortaya çıkan dosyanın çalıştırılabilir olmasına denir.
Rust'da derleme süreçleri şu şekildedir.

Cargo Check

Bu komut, kodda herhangi bir hatanın veya uyarının olup olmadığını kontrol eden ve bir çıktı olarak bizlere göstermektedir. Aynı komutu projemize yazarsak, aynı şekilde bizlerde sonucu gözlemleyebiliriz.
cargo check

Cargo Build

Bu komutta hatasız olan Rust kodunu Assembly diline akabinde çalıştırılabilir dosyaya derler.
cargo build

Cargo Run

Bizimde sıklıkla kullanıcağımız bu komutta, bahsettiğimiz komutlara ek olarak bir de derlenen programı çalıştıran bir komuttur.
cargo run

Rustc

Rustc, Cargo aracının temelinde yatan araçtır. Bu araç, bizlere proje oluşturmadan tekli Rust kaynak dosyalarını derlememizi sağlar.
Örnek olarak, başka bir klasörün içerisine "main.rs" adlı kod dosyasını oluşturalım ve şu komutları yazalım;

fn main()
{
    println!("Merhaba, Rust programcısı!");
}

Ardından

rustc main.rs
./main # Linux
main # Windows

Çıktısı ise;

Sürümler Arası Geçiş

Açtığımız projeye geri dönelim. Projenin klasöründe "Cargo.toml" adlı bir dosya görüceksiniz. Bu dosya projemizin paket yöneticisidir. Bu kısımda yazılan kütüphaneleri kolayla programıza katabilir. İçerisinde sürüm bilgileride bulunur.
# <- Toml için yorum satırı

[package]
name = "ilkProjemiz"
version = "0.1.0"
edition = "2024" # <- Bu kısım

[dependencies]

"edition" kısmı, projenin hangi Rust sürümünü kullanıcağını ifade eder. Rust sürümleri ise üç yıl arayla çıkan stabil Rust programlama dilinin sürümleridir. Aşağıda sürüm yılları verilmiştir;

  • 2021
  • 2018
  • 2015
